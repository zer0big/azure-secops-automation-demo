## 문제 정의

### 비즈니스 요구사항
Azure API Management (APIM) 게이트웨이 로그에서 오류를 모니터링하고 Azure DevOps에 자동으로 인시던트 티켓을 생성하며 다중 채널 알림을 제공합니다.

### 기술적 과제
1. **커넥터 제한**: 사전 구축된 DevOps 커넥터 불안정
2. **인증 복잡성**: PAT 토큰 및 비밀 회피
3. **일정 정밀도**: 타임존 인식 일일 실행
4. **오류 처리**: 오류 존재에 대한 조건부 로직

### 성공 기준
- ✅ 자동 오류 감지 (24시간 범위)
- ✅ 수동 개입 없이 DevOps 작업 항목 생성
- ✅ Teams 및 이메일 알림
- ✅ 보안 인증 (관리 ID)
- ✅ 특정 시간에 일일 실행 (오전 7시 KST)

### 2단계: 쿼리 개발

**KQL 쿼리**:
```kusto
ApiManagementGatewayLogs
| where TimeGenerated > ago(24h)
| extend KST = TimeGenerated + 9h
| where ResponseCode != 200
| project KST, TimeGenerated, CorrelationId, ApiId, OperationId, 
          ResponseCode, BackendResponseCode, CallerIpAddress, Method, Url, LastErrorMessage
| order by TimeGenerated desc
| take 50
```

**주요 기능**:
- 24시간 조회 범위
- KST 타임존 변환
- 200이 아닌 응답 필터링
- 상위 50개 결과 (성능)

### 3단계: 관리 ID 구성

**Logic App ID**:

# Azure DevOps (수동 설정 필요)

### 4단계: DevOps 작업 항목 생성

**HTTP 액션 구성**:
```json
{
  "method": "POST",
  "uri": "https://dev.azure.com/{org}/{project}/_apis/wit/workitems/$Issue?api-version=7.0",
  "headers": {
    "Content-Type": "application/json-patch+json"
  },
  "authentication": {
    "type": "ManagedServiceIdentity",
    "audience": "499b84ac-1321-427f-aa17-267ca6975798"
  },
  "body": [
    {
      "op": "add",
      "path": "/fields/System.Title",
      "value": "@{concat('APIM 오류 - ', body('Query_APIM_Logs')?.tables?[0]?.rows?[0]?[4])}"
    },
    {
      "op": "add",
      "path": "/fields/System.Description",
      "value": "<h2>오류 세부정보</h2>..."
    },
    {
      "op": "add",
      "path": "/fields/System.AssignedTo",
      "value": "user@example.com"
    },
    {
      "op": "add",
      "path": "/fields/Microsoft.VSTS.Common.Priority",
      "value": 2
    }
  ]
}
```

**중요 세부사항**:
- Content-Type은 반드시 `application/json-patch+json`이어야 함
- Audience는 반드시 `499b84ac-1321-427f-aa17-267ca6975798` (Azure DevOps 리소스 ID)이어야 함
- Body 형식: JSON Patch 배열

## 문제 해결 여정

### 문제 1: 커넥터 NotFound 오류
**증상**:
```json
{
  "code": "NotFound",
  "message": "The API 'visualstudioteamservices' operation 'CreateWorkItem' is not found."
}
```

**조사**:
1. API 연결 정의 확인
2. 지역에서 커넥터 가용성 확인
3. Azure Portal 커넥터 목록 검토

**해결책**: REST API가 포함된 HTTP 액션으로 전환

### 문제 2: UTF-8 BOM 인코딩
**증상**:
```
json.decoder.JSONDecodeError: Unexpected UTF-8 BOM
```

**근본 원인**: Python 스크립트가 BOM으로 파일 작성

**해결책**:
```python
# 인코딩 변경
with open('template.json', 'w', encoding='utf-8-sig') as f:
    json.dump(template, f, indent=2, ensure_ascii=False)
```

### 문제 3: 중복 액션 이름
**증상**:
```
InvalidTemplate: The template action 'Create_DevOps_Work_Item' is defined multiple times
```

**근본 원인**: Python 스크립트가 이전 액션을 삭제하지 않고 추가

**해결책**:
```python
# 새 액션을 추가하기 전에 이전 액션 삭제
if 'Create_DevOps_Work_Item' in template['resources'][3]['properties']['definition']['actions']:
    del template['resources'][3]['properties']['definition']['actions']['Create_DevOps_Work_Item']
```

### 문제 4: 관리 ID 401 Unauthorized
**증상**: DevOps API 호출 시 HTTP 401

**근본 원인**: Logic App ID에 DevOps 권한이 부여되지 않음

**해결책**:
```bash
# 수동 단계 필요
1. 이동: https://dev.azure.com/{org}/{project}/_settings/security
2. Logic App 시스템 할당 ID 추가
3. "Contributor" 또는 "Work Item Writer" 역할 부여
```

## 배운 교훈

### 1. 커넥터가 항상 안정적인 것은 아님
**교훈**: 사전 구축된 커넥터는 지역 가용성 문제나 API 정의 불일치가 있을 수 있습니다.  
**권장사항**: 중요한 워크플로우의 경우 직접 REST API 호출이 포함된 HTTP 액션을 사용하세요.

### 2. 관리 ID > PAT 토큰
**교훈**: 관리 ID는 비밀 관리를 제거하고 자동 순환을 제공합니다.  
**권장사항**: 가능한 경우 항상 관리 ID를 선호하세요.

### 3. 단일 리소스의 경우 ARM 템플릿 > Terraform/Bicep
**교훈**: 간단한 배포(1-2개 리소스)의 경우 ARM 템플릿이 더 빠르고 안정적입니다.  
**권장사항**: 복잡한 다중 리소스 배포에는 IaC 도구(Terraform/Bicep)를 사용하세요.

### 4. 타임존 인식이 중요함
**교훈**: UTC 전용 일정은 다른 타임존의 사용자에게 혼란을 줄 수 있습니다.  
**권장사항**: Recurrence 트리거에서 항상 타임존을 명시적으로 지정하세요.

### 5. JSON Patch 형식은 엄격함
**교훈**: DevOps 작업 항목 API는 정확한 `application/json-patch+json` 콘텐츠 타입이 필요합니다.  
**권장사항**: API 문서를 주의 깊게 읽으세요. 콘텐츠 타입이 중요합니다.

### 6. Python UTF-8 인코딩 함정
**교훈**: 기본 UTF-8 인코딩에는 BOM이 포함될 수 있어 JSON 파서를 손상시킬 수 있습니다.  
**권장사항**: JSON 파일 생성에는 `encoding='utf-8-sig'`를 사용하세요.

### 7. 문서화가 중요함
**교훈**: 복잡한 통합에는 유지보수를 위한 포괄적인 문서가 필요합니다.  
**권장사항**: 아키텍처, 구현 및 문제 해결 단계를 문서화하세요.
